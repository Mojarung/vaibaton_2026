# Производительность и доп. возможности

## Цель

Ориентир оргов: latency не больше 0,5 с при 1000 RPS, повышенный уровень 2000 RPS. Автопроверка
разгоняет нагрузку до пиков в 1000 RPS из 200 соединений и смотрит среднее, p50, p95 и p99.

## Стенд

| Что | Значение |
|---|---|
| Хост | Windows 11 Pro, 12 логических ядер |
| API | контейнер с лимитом `API_CPUS` (по умолчанию 4), granian в режиме `mt`, воркеров столько же, сколько CPU, Python 3.14 |
| Хранилище | Redis 8.8.3 в отдельном контейнере на 1 CPU |
| Генератор нагрузки | k6 2.3.0 на том же хосте, делит с API общие ядра |
| Сценарий | `load/process.js`: пара маска/демаска с одним `payload_id`, 200 соединений, разгон 20 с |
| Тексты | 85% одно значение или фраза, 13% абзац из 8 примеров, 2% длинный текст из 60 примеров |
| Проверка | каждая демаска сверяется с исходником посимвольно, расхождение считается ошибкой |

Запуск: `RATE=1000 DURATION=300s sh load/run.sh`. Скрипт поднимает API, ждёт healthcheck,
запускает k6 и печатает одну строку сводки.

## Результаты

| CPU | Цель | Факт RPS | p50, мс | p95, мс | p99, мс | max, мс | Ошибки | Неточные восстановления |
|---|---|---|---|---|---|---|---|---|
| 4 | 1000 RPS, 5 минут | 968 | 18,7 | 232,5 | 371,0 | 1079 | 0% | 2 |
| 4 | 2000 RPS, 1 минута | 1237 | 108,7 | 323,1 | 435,8 | 770 | 0% | 0 |

Факт RPS ниже цели на время разгона. Все числа сняты на одном хосте, где k6 конкурирует с API за
ядра, на выделенной машине с отдельным генератором мы не мерили.

## Цена запроса

| Что | Время |
|---|---|
| Детекция, смешанный слепой набор | около 1 мс на текст |
| Текст ~100 тыс. токенов (360 тыс. символов), тест `test_big_text` | 3,7 с на пару маска/демаска |
| Тот же объём, где ПДн в каждой строке | около 16 с на пару |

## Метрики в работе

`GET /stats` отдаёт RPS, TPS и перцентили за последние 60 секунд, собранные со всех воркеров.
`GET /metrics` отдаёт гистограммы Prometheus, дашборд Grafana поднимается командой
`docker compose --profile observability up -d`. TPS считается как символы / 3,5: это оценка
для русского текста, без токенизатора конкретной модели.

## Доп. возможности (критерий 3.7)

| Возможность | Где посмотреть |
|---|---|
| Токенизация и синтетические данные | `mask_mode: placeholder` даёт обратимые токены `[ФИО_1]`, `mask_mode: synthetic` подставляет правдоподобные ФИО, карты с верной контрольной цифрой, телефоны `+7 9xx`; оба режима демаскируются. Система `crm` в демо |
| Вид маски под систему и под тип | `mask_mode` и `type_modes` в `config/systems.yaml`: у `crm` синтетика, а карта открыта частично |
| 2000 RPS при latency до 0,5 с | факт RPS 1237 и p99 435,8 мс |
| Документы кроме паспорта РФ | тип `FOREIGN_DOCUMENT`: загранпаспорт, паспорт иностранца, вид на жительство, РВП, свидетельство о рождении, военный билет, ID-карта, паспорт моряка; плюс водительское удостоверение и СНИЛС отдельными типами |
| Маскирование по комбинации | `combo_rules` в политике: у `support_bot` PIN и CVV маскируются только рядом с номером карты, окно настраивается |
